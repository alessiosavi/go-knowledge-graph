# go-knowledge-graph (`gkg`)

**Document → knowledge graph → agent queries.** Ingest a document (text,
file or URL), extract entities and relations into
[Memgraph](https://memgraph.com) with full provenance, and query the graph
from agents over MCP + REST — with judge-based quality measurement.

> Status: v0.1.0 under construction. This repository is built task by
> task; the quickstart, agent setup guide and known limitations land with
> the release.
